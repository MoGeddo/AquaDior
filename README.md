تطبيق خاص بشركة واحدة — العمال يسجّلوا حضورهم والفلوس اللي بياخدوها، والمالك/المدير بيتابع ويسوّي التسويات.

**الحالة الحالية:** ✅ كل الواجهات شغالة + وضع تجريبي ببيانات وهمية.

## 1. شغال بإيه دلوقتي (وضع تجريبي)

التطبيق شغال **من غير أي إعداد** ببيانات وهمية. جرّبه:

## شاشة الدخول — واحدة وبسيطة

**اسم المستخدم + كلمة سر بس.** والنظام بيعرف الدور لوحده من اسم المستخدم:

| الدور | اسم المستخدم | كلمة السر |
|---|---|---|
| 👑 **مالك** — عابدين يونس | `abden.younes` | `Qn&112233#Do` |
| 👑 **مالك** — محمود عبدين | `mahmoud.abdin` | `Qn&112233#Do` |
| 🛠️ **مطوّر** — Mostafa Geddo | `MostafaGeddo` | `Qn&112233#Do` |
| 👷 **العمال** | اسم مستخدم خاص بكل واحد | اللي اختاروه وقت التسجيل |

- الملاك والمطوّر → لوحة التحكم
- العمال → صفحة العمال (حضور + فلوس + كشف)

**وتحته لينك واحد:** `سجّل حساب جديد` — للعمال اللي أول مرة (مرة واحدة بس، وبعدين بيدخلوا باسم المستخدم وكلمة السر).

### 🔒 قفل المشروع والأرشيف (البيانات متتمسحش)

- **قفل المشروع ما بيمسحش أي بيانات** — كل سجلات الحضور والفلوس والخصومات بتفضل في الداتابيز للأبد.
- القفل بيقفل حسابات العمال في المشروع ده بس (ما يسجّلوش فيه تاني).
- بيولّد **تسوية نهائية** لكل عامل، والمشروع يروح لتبويب **📦 الأرشيف**.
- تقدر **تصدّر المشروع كامل CSV** (عمال + حضور + فلوس + خصومات + تسويات) في أي وقت.
- العامل من شاشته يشوف: *"مشروعك اتقفل"* + ملخص فلوسه + لينك كشف الحساب.

### 🛡️ الأمان
- العامل يقرأ بياناته هو بس (RLS) — مبيشوفش يوزرات أو فلوس حد تاني.
- سجل التعديلات والإشعارات للمالك والمطوّر بس.
- صور البطاقات في مخزن مقفول — العامل يرفع في فولدره بس، والإدارة بس اللي تقرا.
- الإعدادات الداخلية للإدارة بس.

### 🛠️ صفحة المطوّر (MostafaGeddo)
صفحة خاصة بتقدر منها:
- **👥 كل اليوزرات**: تعديل اسم/يوزر/دور/حالة/يومية/كلمة سر لأي حد
- **🔧 التشخيص**: حجم الداتا، العمليات اللي مش بترتفع، آخر خطأ، وحلول سريعة
- **🛡️ سجل التعديلات**: مين عدّل إيه وإمتى

في الوضع التجريبي كمان في **طلب تسجيل مستني موافقة** (`sayed.ali` / `01155555555`) تقدر تجرّب بيه صفحة طلبات التسجيل.

في الوضع التجريبي تقدر:
- تسجّل حضور، تختار مواقع، تاخد فلوس، تشوف كشف الحساب
- تدخل لوحة المالك وتشوف الداشبورد، توافق على طلبات، تخصم، تقفل مشروع

## تجربة العمال في اليوم العادي

**الصبح أول ما ينزل (3 ثواني):**
> يفتح الأبليكيشن → يضغط **"⬇️ نزلت النهاردة"** → يختار الموقع (أو أكتر) → تم.

**لو راح موقع تاني بعد كده (3 ثواني):**
> من الشاشة الرئيسية → **"+ موقع"** → يختار الموقع الجديد. (مبيسجّلش حضور تاني — اليومية واحدة)

**كل مرة ياخد فيها فلوس (5 ثواني):**
> من الشاشة الرئيسية → **"💵 خدت فلوس"** → يكتب المبلغ → **"تم"**.
> بيتسجّل **كل مرة لوحدها**، مش مرة واحدة في آخر اليوم — عشان الدقة.

**ملاحظات:**
- زر "خدت فلوس" **مبيظهرش** غير لما يسجّل حضوره
- العامل **ما ياخدش** أكتر من استحقاقه (التطبيق هيرفض)
- اللي تحت 500 جنيه بيعدّي لوحده، واللي فوقه بيحتاج موافقة المالك
- التعديل مسموح **في نفس اليوم بس**

## 1.5 تسجيل العمال الجدد (مرة واحدة بس)

**العامل بنفسه:**
1. يفتح اللينك → **"تسجيل جديد"**
2. بيسجّل: رقم الموبايل + **الاسم زي البطاقة** + **صورة البطاقة** + اسم مستخدم + كلمة سر
3. بيظهرله: *"حسابك مستني تفعيل المالك"*

**المالك:**
1. **لوحة التحكم → طلبات التسجيل** (بيوصلو إشعار على تليجرام كمان)
2. يشوف صورة البطاقة ويتأكد إن الاسم مطابق
3. يضغط **"فعّل"** → يحدد اليومية والمواقع
4. العامل بيقدر يدخل من غير أي مشكلة

**بعد كده** العمال بيدخلوا بـ **اسم المستخدم وكلمة السر** (مش تسجيل تاني).

## 3. ربط قاعدة البيانات الحقيقية (مجاني)

### الخطوة 1 — Supabase
1. روح [supabase.com](https://supabase.com) → **New Project** (مجاني)
2. من القائمة: **SQL Editor** → شغّل الملفات دي **بالترتيب**:

| # | الملف | بيعمل إيه |
|---|---|---|
| 1 | `supabase/schema.sql` | الجداول + الـ views |
| 2 | `supabase/policies.sql` | الصلاحيات (العامل يشف بياناته بس) |
| 3 | `supabase/triggers.sql` | سجل التعديلات + الإشعارات + قفل المشروع |
| 4 | `supabase/functions.sql` | دوال تسجيل الحضور والأخذ وإنشاء العمال |

### الخطوة 2 — المفاتيح
1. **Project Settings → API**
2. انسخ `Project URL` و `anon public key`
3. حطهم في ملف `.env`:

```env
VITE_SUPABASE_URL=https://cggqzwnxbayghramabo.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

### الخطوة 3 — أول حساب مالك
من **SQL Editor**:

```sql
-- غيّر الاسم والرقم والباسورد
select create_worker('محمد المالك','01xxxxxxxxx','12345678',0,null,null);

-- حوّله لمالك
update profiles set role='owner' where phone='01xxxxxxxxx';
```

بعدها سجّل دخول بالموبايل وكلمة السر اللي حطّتهم.

## 4. إشعارات تليجرام (مجاني)

1. على تليجرام: **@BotFather** → `/newbot` → انسخ التوكن
2. **@userinfobot** → انسخ الـ Chat ID

## 5. تشغيله على موبايلات العمال (بدون متاجر)

### الطريقة 1 — PWA (الأسهل، أندرويد + آيفون) ⭐
1. ارفع مجلد `dist/` على استضافة مجانية:
   - **Cloudflare Pages** / **Vercel** / **Netlify** (اسحب المجلد وخلاص)
2. ابعت اللينك للعمال
3. **أندرويد:** Chrome → قائمة → **"إضافة للشاشة الرئيسية"**
4. **آيفون:** Safari → Share → **"Add to Home Screen"**

هيظهرلهم أيقونة زي أي أبليكيشن، وبيشتغل أوفلاين.

### الطريقة 2 — APK للأندرويد بس
```bash
npm i -g @bubblewrap/cli
bubblewrap init --manifest https://YOUR-DOMAIN.com/manifest.webmanifest
bubblewrap build
# بيطلّع app-release-signed.apk — ارفعه على أي لينك وخلّي العمال يحمّلوه
```

## 6. إزاي بيشتغل أوفلاين

- كل تسجيل بيتحفظ في الموبايل فورًا (IndexedDB)
- لو مفيش نت، بيظهر شريط برتقالي: *"مفيش نت — العملية هتتسجّل أول ما النت يرجع"*
- أول ما النت يرجع، العمليات كلها تترفع تلقائيًا

## 7. القواعد المطبّقة في الكود

| القاعدة | مكانها |
|---|---|
| العامل ما ياخدش أكتر من استحقاقه | `register_withdrawal()` في `functions.sql` |
| يومية واحدة حتى لو أكتر من موقع | `register_attendance()` + `unique (worker_id, work_date)` |
| تحت السقف يعدّي لوحده، فوقه موافقة | `notify_withdrawal()` في `triggers.sql` |
| أي تعديل → إشعار + سجل | `log_audit()` + `notify_admins()` |
| العامل يعدّل نفس اليوم بس | RLS policy في `policies.sql` |
| المالك والمدير بس يشوفوا الكل | RLS policy في `policies.sql` |
